# Web development

Three standalone JavaScript projects for practicing browser and full-stack development. Run each project from its own directory.

| Project | Focus |
| --- | --- |
| [Wordle](wordle/) | Vanilla JavaScript, HTML, CSS, and game state |
| [BlindChat](blindchat/) | React, Firebase Authentication, and real-time Firestore data |
| [Books of Gold](books-of-gold/) | React storefront, admin dashboard scaffold, and an Express/MongoDB API |
